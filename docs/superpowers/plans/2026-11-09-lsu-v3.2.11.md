**Tech Stack:** C++17 (vendored gem5 v25.1.0.1, SCons), Python 3.11 (gem5 stdlib config, pilot platform, pytest, openpyxl), AArch64 host `gcc -O2 -static`.

## Review Focus

1. **Historical artifacts must not be touched.** A report or matrix step that writes into `pilots_v3_2_*` invalidates the evidence chain. Task 9 verifies `sha256sum` before/after extraction and Task 21 asserts `git status --short` has no `pilots_v3_2_*` entry.
2. **Time adjacency is not causality.** The audit tool must only create a chain edge from an explicit `ptag`, `dyn_inst_seq`, or data-hash link. Task 8's synthetic test has two adjacent events with no link and must return `PARTIAL`/`UNRESOLVED`, never `COMPLETE_CAUSAL_CHAIN`.
3. **Control runs are not failed fault runs.** Task 4 pins `run_role=CONTROL`, `control_valid=true`, `accepted=true` for an oracle-passing zero-injection run.
4. **Watchdog must exit cleanly and never be MASKED.** Task 5 asserts non-zero exit, the `CHAOS_LQ04_WATCHDOG_EXPIRED` line, absence of `NotImplementedError`, retained trace events, and `classify` returning `TIMEOUT`/`HANG` rather than `MASKED`.
5. **Mixed binaries must not be aggregated.** Task 8's `audit_pilot` refuses to compare a pilot's recorded binary SHA with a different audit binary; Task 21 emits per-binary splits in the matrix instead of a merged verdict.
