- Do **not** modify the other 11 fault models. No 60-sample formal run.

- Do **not** overwrite historical pilots or traces. New supplementary runs go in new versioned directories.

- MD04 is a **report-suppression** fault: no address/size/data/other-LSQ-state change.
- FW05 is **single wrong-source forwarding**: no multi-store splice, no byte-lane skew, no data corruption. If the hook cannot prove two different stores with different data and full coverage of the load by the alternative store, it declines.

## Review Focus

1. **Ordinal drift after widening the MD04 eligibility rule.** The frozen rule includes real byte-overlap aliases (e.g. a 16-byte LDP covering an 8-byte store) that the old exact-start-address rule missed. A target `EventOrdinal` can therefore map to a different pair. Every historical pilot must be re-adjudicated as *injection-conforming* vs *configuration-conforming*; a new event stream proof must accompany the re-run.
2. **Cross-attempt stitching.** R03's injection is attempt 1 and its response/writeback/commit are attempt 2. The validator must refuse to stitch without (dyn seq, LQ entry, entry generation, request id) identity evidence, even though the current trace looks "complete".
3. **FW05 alternative-store alignment.** The existing call site copies `alt->data()` from offset 0. FW05 must shift by `load_addr - alt_addr` and decline unless the alternative store fully covers the load range; otherwise the fault silently becomes a garbage splice.
4. **FW05 data equality.** If the true and alternative stores hold identical bytes, the "fault" is unobservable. Such an event is not eligible and must not be counted as an injection.
5. **FW05 downstream hash continuity.** The load's response, PRF writeback and consumer input must all hash to the alternative store's bytes; a mismatch is a chain FAIL, not a MASKED result.

```cpp
inline bool
isEligibleViolationPair(uint64_t load_addr, unsigned load_size,
                        uint64_t store_addr, unsigned store_size,
                        unsigned dep_check_shift)
{
    if (store_size != 8 || load_size < 8)
        return false;

    const uint64_t s_lo = store_addr;
    const uint64_t s_hi = store_addr + store_size - 1;
    const uint64_t l_lo = load_addr;
    const uint64_t l_hi = load_addr + load_size - 1;

    // "Different address" is excluded: require a real byte overlap.
    if (s_hi < l_lo || l_hi < s_lo)
        return false;

    // Same shifted-range predicate as LSQUnit::checkViolations.
    const uint64_t ss_lo = store_addr >> dep_check_shift;
    const uint64_t ss_hi = (store_addr + store_size - 1) >> dep_check_shift;
    const uint64_t ls_lo = load_addr >> dep_check_shift;
    const uint64_t ls_hi = (load_addr + load_size - 1) >> dep_check_shift;
    return ss_hi >= ls_lo && ss_lo <= ls_hi;
}
```

- [ ] **Step 3: Implement the rules**

```cpp
#pragma once
#include <cstdint>
#include <cstring>
#include "base/types.hh"

namespace gem5 { namespace chaos_fw05 {

struct Candidate {
    uint64_t seq = 0;
    Addr addr = 0;
    unsigned size = 0;
    const uint8_t *data = nullptr;
};

inline bool
isEligible(uint64_t load_seq, Addr load_addr, unsigned load_size,
           const Candidate &true_src, const Candidate &alt_src,
           unsigned &alt_offset)
{
    alt_offset = 0;
    if (!true_src.data || !alt_src.data)
        return false;
    if (true_src.seq == alt_src.seq)
        return false;                       // must be different dynamic stores
    if (alt_src.seq >= true_src.seq)
        return false;                       // alternative must be older
    if (load_seq <= true_src.seq || load_seq <= alt_src.seq)
        return false;                       // load must be younger
    if (load_size == 0 || true_src.size < load_size)
        return false;                       // true source must cover
    if (alt_src.addr > load_addr)
        return false;                       // must cover the load's first byte
    const uint64_t off = load_addr - alt_src.addr;
    if (off + load_size > alt_src.size)
        return false;                       // no multi-store splice
    alt_offset = (unsigned)off;
    return true;
}

inline bool
bytesDiffer(const uint8_t *a, const uint8_t *b, unsigned n)
{
    return a && b && n > 0 && std::memcmp(a, b, n) != 0;
}

}}
```
