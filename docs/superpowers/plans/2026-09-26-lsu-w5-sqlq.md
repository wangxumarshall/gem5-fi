# LSU W5 — SQ/LQ 注入器（S01–S13 + L01–L04，96 格）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans / subagent-driven-development。

**Goal:** S 系 13 + L 系 4 模型的注入面落地（96 格），通过 **TC'23 锚点（M2 门）**：S01/S13/L01 单 bit 复现 TC'23 的 LQ/SQ SDC=0%。

**Spec:** `03-design-matrix` S/L 行（模型全文已提取入本计划前序对话，见 design-matrix.csv）+ `09 §3 W5` + `§2.1 ①②`（LQ/SQ 结构 + StoreSet 落点）+ TC'23 对照（`01-units-and-research` r4/r8：LQ/SQ SDC=0，每负载 2000 次）。
