## 设计结论（从证据推导，不是猜测）

### A05（AGU 操作数选择）

DIAG-B 实测：`LSQ::pushRequest` 阶段只剩合成后的 EA；microop 源操作数槽非稳定 API
（已实测 SIGSEGV）。唯一干净插入点 = ISA `buildEACode()` 生成的 `ea_code`，
在 EA 表达式处拿到真实 `XBase/XOffset/type/shiftAmt/base/offset/size`。

采用 DIAG-B「设计 A」：ISA 生成代码在 EA 计算前调用
`ArmISA::chaosAguRegOperands(...)`（新文件 `chaos_agu_operands.{hh,cc}`），
回调进入 `CHAOSAddrPath`（RTTI 取 `o3::DynInst`，按 `cpu` 指针确认本核），
在那里完成：onAttempt/资格判定/onEligible/计数/证据；只改写**局部**操作数
副本，绝不原地改 `StaticInst::type/shiftAmt`（跨动态实例共享），绝不改写
架构寄存器。

- A05-a base/index 互换：`shift!=0` 才 eligible；`new_EA = index + extend(base)`。
- A05-b UXTW↔SXTW：仅 `type∈{UXTW,SXTW}` 且 `bit31(index_val)==1` 才 eligible；
  否则 no-op 前置拒斥，不消费预算。
- A05-c shift 另一合法值：`shift' = (shift ? 0 : log2(size))`；`size==1` 或
  `index_val==0` 或新 EA 不变 ⇒ 前置拒斥，不消费预算。
- A05-d 保持 pushRequest 处既有 pre/post 反转（已实测，不改）。
- 幂等：按 `(seqNum, pc, staticInst)` 单槽缓存决策；重复执行（翻译延迟重执行）
  重放同一决策，不重掷、不二次计数。
- request-scoped 交接：ISA 钩子登记 pending（真实 old/new EA + 操作数字段），
  `pushRequest` 用同一身份 claim 一次；未 claim 的旧登记在下一次新登记时回收
  并计数（`obs_a05_stale_reclaimed`），绝不跨指令串链。
- 证据：claim 点写一条注入日志（old/base/index/type/shift/EA、dyn seq、pc、
  opcode、request/corr 由既有 `registerInjection` 交付）；`lsq.cc` 用
  `lastPreFaultOldAddr()` 登记真实旧 EA（非 ISA 路径行为不变）。

### A08（通道 / 同周期 EA 互换）

DIAG-C §2 实测：`Request` 在 PRE hook 之后构造；load 侧窗口≈0，store 侧在
`LSQUnit::writebackStores` → `request->buildPackets()`（`lsq_unit.cc:1036`）
之前有长窗口；`Request::setPaddr` 可写，但没有请求级重翻译设施。

- 同周期配对登记：`CHAOSAddrPath` 在 `LSQ::pushRequest` 记录
  `(tid, curTick, seq, addr, size, is_load, DynInstPtr)`；只有**同一 tick**
  的 load+store 才构成候选；store 必须先于 load（store→load），否则
  `pair_order=store_after_load` 拒斥。跨周期不配对。
- A08-a（错通道）：对配对的 store，在 `buildPackets()` 建包后把命令
  `WriteReq → ReadReq`（真实进入 packet；`inst->isLoad()==0`、
  `request->isLoad()==0` 保留，故证据可证"store 走 load 访问类型"）。
  包命令由请求侧标志 decide；不改 `inst->isLoad()`（禁）。
  load→store 方向在定宽 load 完成合同下结构性不可行 ⇒ 显式 decline 计数。
- A08-b（同周期 EA 互换，store→load 顺序）：
  - load 侧：在其 pushRequest 把 EA 换成配对 store 的真实 EA，随后正常翻译
    ⇒ load 的 TLB/cache 访问的就是 store 地址。
  - store 侧：writeback 前检查 `(load_ea>>12)==(store_ea>>12)` 且
    `(store_pa&0xFFF)==(store_va&0xFFF)`（真实 4KiB 页、偏移保序），通过后
    `setPaddr(page_base_of_store_pa | (load_ea&0xFFF))`（split 各片按 delta 同步）。
  - 跨页/跨周期/缺配对/一方已结束/已发送 ⇒ decline（计数），不消费预算。
  - 事件记录双方 seq/request_id/old-new EA/PA/tick/拒绝原因。
- 触发：A08 两个子模型共用"同 tick load+store 配对"资格；attempted =
  每次 pushRequest 的候选，eligible = 通过配对与语义检查的配对事件。
  F0/F2 的 span 以实测配对流为准（canary 后写回 `ADDRPATH_F0_SPAN`）。
