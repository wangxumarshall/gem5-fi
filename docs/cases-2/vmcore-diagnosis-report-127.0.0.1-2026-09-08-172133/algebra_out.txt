六、总结(代数与形态)
========================================================================
1.【实锤】x27 = x1 + x20 (mod 2^64) 逐位闭合 → add 指令与操作数传递无错。
2.【实锤】FAR = x27 + 0x120 (mod 2^64) 逐位闭合 → 缺页地址为 x20 坏值的

   非 percpu 偏移合法形态(高16应 ffff、低13~16应页对齐 0)。

   呈 rol16 关系(仅 7/64 位差异)——16bit lane 错位族形态学指纹,
   归并谱系 lane 错位族(#1/#5/#7),其中 #7(ror16+0xa000 顶标签)最相似。
