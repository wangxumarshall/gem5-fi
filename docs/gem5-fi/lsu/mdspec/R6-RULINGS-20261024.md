# R6 用户裁决存档（2026-10-24，权威续篇）

## 裁决 D — `time_reversed_edge` 归责与严格性

- **归发射器/事件生成顺序负责；checker 保持严格，不得放宽或删除该拒绝。**
- 合法关系必须满足 **`parent.tick <= child.tick`**。
- 对 `request_fork` 必须满足 **`source.tick <= bridge.tick <= destination.tick`**。
- **同 tick 允许**；`parent.tick > child.tick` **不允许**。
- 若当前重跑出现 `time_reversed_edge`：**先保存完整复现证据**；**不得修改正在使用的候选二进制**。
  **当前 wave 结束后**再指定唯一修复者，重建 SHA，并**重跑所有受影响 RunID**。
