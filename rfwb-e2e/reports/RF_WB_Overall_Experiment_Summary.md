## 关键机制

- **M001**：GPR Physical Register File 驻留值单比特翻转。GPR PRF 驻留槽位（SimpleFreeList 分配，flat PhysRegId + AllocationGeneration）。
- **M002**：FP/SIMD Physical Register File 目标 byte 清零。FP/SIMD VecReg writable operand 的 shadow 写入代理（EOR .16B 目的）。
- **M003**：Register Read Port 返回值瞬态翻转。Rename/Read Port 返回副本（PRF 读出的临时值，不回写 PRF）。
- **M004**：Writeback 完成通知（instToCommit）漏发。IEW → Commit 的完成通知 / instToCommit 队列项。
- **M005**：全局 Register Ready 置位漏发。IEW 全局 ready bitmap（setReg 全局置位）。

## 证据边界

- 消费者按 PhysRegId + AllocationGeneration 过滤；Batch02 14 列 Trace 无 gen 时标 `NA`，不用后续重用读替代同版本证据。
- `M003_PRF_READ` 只用于 PRF 驻留值完整性检查；`M005` 的正确数据读取不称为 faulted read。
- M004 的 Squash 不是数据消费者；13 个 ROB_HEAD_BLOCKED 样本没有软件输出。
- 未直接观察的中间步骤标 `NOT_OBSERVED`；由汇编/寄存器重定义推断的关系标 `INFERRED`，不标 OBSERVED。
