三、以 Markdown 为规格进行实现

1. 为每个 RunID 建立“规格→命令行参数→注入点→监控钩子→结果字段”的可机读映射。
2. 严格实现表 9 的：
   - 完整传播路径；
   - 必监控单元/事件/指标；
   - 跨单元关联键；
   - 完整性/传播终止判定；
   - 缺失监控及新增钩子。
3. 必须保存：
   - run_id、sample_run_id、fault_id/ptag；
   - event_id、parent_event_id；
   - dyn_inst_seq、commit_seq、PC/opcode；
   - request_id、walk_id、mshr_id、fill_id；
   - LQ/SQ index、VA/PA/cache line；
   - 各单元关键指标 before/after；
   - first divergence；
   - 最终 SDC/Detected/Masked/Crash/Timeout/SimFailure/Unknown 及证据。
4. 禁止只用 tick 或 address 作为跨单元关联键。
5. 链路在某节点中断时，只能标记“截至该节点可证，后续 Unknown”，不得推断 Masked。
6. 不得为了让运行通过而改变 Markdown 的模型语义、RunID 或激活口径。
