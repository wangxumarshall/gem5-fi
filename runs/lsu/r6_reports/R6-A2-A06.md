# R6-A2 A06 裁决落地（2026-10-28）

## 语义（用户裁决）

- **A06-a**：store 合法向下缩小 `target = original/2`（2→1, 4→2, 8→4, 16→8）。
  要求 `addr % original_size == 0`、target 是合法 AGU size。
  非对齐 / size=1 / **任何 load** ⇒ ineligible，不消费注入预算。
- **A06-b**：同宽、非零、不等于原掩码。原掩码全 1（ISA 常规）⇒ 清最高有效 byte；
  否则按字节循环左移一位。`size=1` / load ⇒ ineligible。
- 子模型由 seed 奇偶选择（A03 先例）：odd=A06-a，even=A06-b。

## 实现

- `LSQ::pushRequest` 构造前（`lsq.cc:800` → `maybeCorruptPre`），唯一安全层。
- 记录：`submodel=a06a|a06b`、`old_size/new_size`、`old_be/new_be`（hex）、
  `EA`、`isLoad/isStore`、`dyn_inst_seq`、`faults_injected`。
- 触发前资格判定（F-049）：load/size=1/非对齐在 trigger 决策前被拒，
  不消耗 F0/F2 预算。
