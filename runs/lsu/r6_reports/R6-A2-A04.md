# R6-A2 A04 对象注册表与同页替换（2026-10-28）

## 实现

- 新增 `aguObjectSpec`（`id:symbol:size:elem` 或 `id:@addr:size:elem`），
  在 `CHAOSAddrPath::startup()` 从 **SE ELF 的 `Process::objFile->symtab()`**
  解析；启动打印 `CHAOS_AGU_OBJECTS:`。
- `a04_same_object`（A04-a）：源 EA 必须完整落在已登记对象内且按访问宽度对齐；
  target 同对象、!=source、按访问宽度对齐、不越界。无对象表/符号缺失/几何不符
  ⇒ **fatal**（绝不退回同页代理）。
- `a04_same_page`（A04-b）：同 4KiB 页，候选按 **访问宽度**（不是固定 16B）
  对齐；`4096/size < 2` ⇒ ineligible。
- 触发前资格判定（F-049）：对象外/不对齐不消费注入预算。
- 记录：`submodel=a04a|a04b`、`object_id/base/size`、`source_offset`、
  `target_offset`、old/new EA。
- W0 `mini_check.c` 的 `data` 重命名为 `oracle_data`（行为/golden 不变），
  消除同名 LOCAL 符号的不确定性。
