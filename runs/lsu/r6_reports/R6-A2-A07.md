# R6-A2 A07 ready 时序（a/b/c）— 2026-10-28

## 实现

- **A07-a `a07a_ready_early`**：ready 点使用**真实保存的旧 EA**（上一条
  访存在 pushRequest 捕获的 EA latch）；pushRequest PRE 把该 EA 装回请求，
  下游 TLB/cache 看到旧 EA。log: `iew_memRef_AGU_ready_early`（stale_ea /
  stale_pa / ready_tick）与 `lsq_pushRequest_PRE mode=a07a_ready_early`
  （old_ea/new_ea/old_pa/stale_ready_tick/consume_tick）。
- **A07-b `a07b_ready_delay`**：既有有界延迟 + resume（保持不变）。
- **A07-c `a07c_ready_loss`**：ready 丢失后调度**有界 watchdog**
  （`aguWatchdogCycles`，默认 4096）；超时三出口：
  已被 squash → `ready_loss_squashed`（L4 contained）；
  仍存活 → `ready_loss_watchdog`（Hardware, hang_recovered）+ 强制 resume；
  超过硬上限 → `exitSimLoop("chaos_ready_watchdog", 124)`。
- 事件挂到该链最后事件（`lastEventId`），保证 L0→L4 前缀可证。
