## 实现机制（不是代理）

- 新文件 `arch/arm/insts/chaos_agu_operands.{hh,cc}`：一个进程级回调 +
  真实操作数快照 `ChaosAguRegView`（dyn_inst_seq/pc/static_inst 身份、
  is_load/size、base/index 寄存器号与**真实值**、extend type、shift）。
- `ldr64.isa`/`str64.isa` 的 register-offset 类在 `buildEACode()` 生成代码里
  **先**把 `XBase/XOffset/type/shiftAmt/base/offset` 复制到局部变量，调用
  `ArmISA::chaosAguRegOperands(...)`，**再**用（可能被改写的）局部值计算
  `EA = base + extendReg64(index, type, shift)`。StaticInst 成员
  `type/shiftAmt` 从不原地写；架构寄存器从不改写。
- `CHAOSAddrPath::maybeCorruptAguOperands`：RTTI 取本核 O3 DynInst，
  身份=seqNum+pc+StaticInst；按身份缓存决策（重复执行/翻译延迟重执行
  **重放同一决策**，不重掷、不二次计数）；资格门在 trigger 之前
  （F-049）：a 要求 shift≠0、b 要求 type∈{UXTW,SXTW} 且 index bit31=1、
  c 要求 size∈{2,4,8} 且 index≠0、且新 EA≠旧 EA，否则计数拒斥、**不消费预算**。
- request-scoped 交接：触发时登记 pending（身份+全部操作数字段），
  `LSQ::pushRequest` 用同一身份 claim 一次（写注入日志 + 交给
  `registerInjection`）；不匹配的 pending 计 `stale_reclaimed` 并丢弃，
  绝不跨指令串链。`lsq.cc` 用 `lastPreFaultOldAddr()` 登记真实旧 EA
  （ISA 路径下传入的 addr 已是故障 EA）。
- 证据：`CHAOS_L0_A05` 汇总行（attempted/eligible/逐原因 declined/
  stale_reclaimed/injected）与 `Site: agu_operand_EA` + `Site:
  lsq_pushRequest_PRE`（claim）双行，含 old/new EA、base/index、type/shift。

```
 dyn_inst_seq=254, pc=0x40c014, opcode=str, old_ea=0x7ffffefc90,
 new_ea=0x3fffff7e090, size=8, isLoad=0, base_reg=3, index_reg=1,
 old_base=0x7ffffefc10, old_index=0x10, new_base=0x10,
```

- 链 10 事件：inj→addr_form→lsq_push→mem_req→sendfrag→tlb_translate→
  tlb_fault→sq_execute→`arch_translation_fault`(L2, contained=1)→chain_end；
  `terminal=detected_contained`，`provable_to=L3`，gzip 完整，stats 235817B。

### A05-b（`--agu_pre_mode a05_extend`）

```
Tick: 15618295, pc=0x4007a4, opcode=ldr, old_ea=0x4919c8,
 new_ea=0x1004919c8, size=8, isLoad=1, base_reg=2, index_reg=1,
 old_base=0x4919d0, old_index=0xfffffff8,
 old_type=6 (SXTW), new_type=2 (UXTW), old_shift=0, new_shift=0
```
- 该 PC 正是载体里的 `ldr x0,[x2,w1,sxtw]`；旧 EA = base−8（对象内），
  新 EA = base+0xfffffff8（≈+4GiB，翻译失败）。
- 链 9 事件，`arch_translation_fault`(L2, contained=1) →
  `terminal=detected_contained`，`provable_to=L2`；途中 101 个 bit31=0
  的 SXTW 事件被前置拒斥（`d_bit31=101`），不消费预算。

### A05-c（`--agu_pre_mode a05_shift`）

```
Tick: 522060, pc=0x40c014, opcode=str, old_ea=0x7ffffefc90,
```
