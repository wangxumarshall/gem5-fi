The release branch contains the code, configuration, workloads, inputs,
manifests and authoritative FINAL reports. The following large evidence is
retained on the original 0101 server and inside the frozen archive
`LSU_E2E_PAPER_FINAL_FROZEN_R2_SUPP1.zip`; it is not required to rebuild or
rerun the experiment.

| Evidence | Why excluded | Server location |
|---|---|---|
| 735 raw prop/commit/stdout traces | large; regenerated by the campaign | `e2e_extension/results/{faults,controls}/` and `results_strict_rp01/` |
| 180 causal-chain JSON/CSV/MD | per-run analysis output; 1.6 GB | frozen ZIP `evidence/causal_chains/` |
| `STRICT_E2E_CAUSAL_EDGES.csv` | 273.8 MB, exceeds GitHub's 100 MB file limit | frozen ZIP `reports/` |
| `SEMANTIC_REVALIDATION_ALL_180.csv.gz` | 30 MB per-instruction ledger | frozen ZIP `evidence/semantic/` |
| 15 RP01 canonical stall traces | small summary/manifest included; raw traces in ZIP | frozen ZIP `evidence/rp01/stall_traces/` |
| six historical squash raw cells | audit summary included; raw When-v2 archive on server | frozen ZIP `evidence/squash/` |

SHA256/size provenance for the raw traces is in
`reports/FINAL_EVIDENCE_MANIFEST.csv` and
`evidence/manifest/STRICT_E2E_LARGE_TRACE_MANIFEST.csv`. The frozen archive
SHA256 is recorded in `SOURCE_VERSIONS.json` and `FREEZE_MANIFEST.json`.
