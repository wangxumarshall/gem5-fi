## Quick start

```bash
git clone https://github.com/wangxumarshall/gem5-fi.git
cd gem5-fi
git checkout mmu-final-reproducible

# 1. build (clean build: -j16)
MMU_FINAL/reproduction/build_mmu.sh

# 2. stage runtime assets (kernel, disk template, checkpoint)
MMU_FINAL/reproduction/prepare_runtime_assets.sh /path/to/server/asset/root

# 3. read-only checks + all 40 describe plans
MMU_FINAL/reproduction/preflight_mmu.sh

# 4. one representative sample
MMU_FINAL/reproduction/run_mmu_sample.sh M01-F0-W9-S01-R01

# 5. verify the archived authority
MMU_FINAL/reproduction/validate_mmu_results.sh
```

`run_mmu_formal_40.sh` and `run_mmu_repeat_10.sh` default to `--dry-run`;
pass `--execute` only when a replication campaign is intended. Output roots
can never be the frozen `runs/MMU_FORMAL_CAMPAIGN_20261113`.

## Scope boundaries

- This branch is MMU-only. `main`, LSU and FSU numbers are unrelated and must
  never be mixed with MMU results.
- SDC here includes permission bypass (M07). It is not only a wrong numeric
  value.
- The frozen binary does not emit per-instruction IFU fetch-response, decode or
  IFU-commit events. Instruction-side samples join MMU translation →
  Execute Request → guest oracle and mark unobserved nodes
  `NOT_EMITTED_BY_FROZEN_BINARY`.
- Four M03 samples end SQUASHED with PARTIAL propagation by design; their raw
  trace is COMPLETE.
- Ten repeat runs validate determinism over the selected contexts; they are not
  a statistical distribution over all possible timings.
- The model semantics are simulator abstractions, not claims about every
  physical ARM implementation.
